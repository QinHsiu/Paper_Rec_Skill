# Method: CRISPE

**id:** `crispe` · **load this file before drafting when CRISPE is selected.**

## When

角色扮演、模拟面试、强人设、指定口吻对话/独白。

## Slots

| Slot | Meaning |
|------|---------|
| **C** Capacity and Role | 能力与角色（完整人设） |
| **R** Insight | 情境洞察/背景 |
| **I** Statement | 具体指令 |
| **S** Personality | 个性、措辞习惯 |
| **P** Experiment | 可尝试的变体/尺度 |

## Fill template

```text
【CRISPE】
Capacity and Role：…
Insight：…
Statement：…
Personality：…
Experiment：…
```

## Draft procedure

1. Emit CRISPE block.
2. Write in-character output; stay inside Personality.
3. Footer: `framework: CRISPE`.
