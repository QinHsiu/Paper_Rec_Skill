# Method: BROKE

**id:** `broke` · **load this file before drafting when BROKE is selected.**

## When

目标导向、多轮迭代、带 KPI/OKR/关键结果的复杂写作项目。

## Slots

| Slot | Meaning |
|------|---------|
| **B** Background | 项目背景 |
| **R** Role | 写作角色 |
| **O** Objectives | 目标 |
| **K** Key Results | 可验收结果（数字/清单） |
| **E** Evolve | 本轮如何改、下一轮评什么 |

## Fill template

```text
【BROKE】
Background：…
Role：…
Objectives：…
Key Results：…
Evolve：…
```

## Draft procedure

1. Emit BROKE block.
2. Draft toward Key Results; list unmet KRs explicitly.
3. Propose Evolve steps for the next round.
4. Footer: `framework: BROKE`.
