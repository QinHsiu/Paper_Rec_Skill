# Method: RASCEF

**id:** `rascef` · **load this file before drafting when RASCEF is selected.**

## When

用户明确要求**分步 / step by step** 执行的写作或改造任务。

## Slots（按步展开）

为每一步写清：目标、输入、动作、验收。步骤数按任务拆，通常 3–7 步。

```text
【RASCEF · 分步】
Step 1：… | 验收：…
Step 2：… | 验收：…
Step 3：… | 验收：…
…
Final deliverable：…
```

## Draft procedure

1. Emit the step plan first.
2. Execute steps in order; show intermediate artifacts when useful.
3. Final = 用户要的成稿。
4. Footer: `framework: RASCEF`.
