# Method: CO-STAR

**id:** `costar` · **load this file before drafting when CO-STAR is selected.**

## When

文案、文章、脚本、小红书、种草、公众号、营销 —— **内容创作默认框架**。

## Slots (fill all)

| Slot | Meaning | Fill rule |
|------|---------|-----------|
| **C** Context | 行业/项目背景 | 品牌、产品事实、场景（不编造） |
| **O** Objective | 要达成的效果 | 关注/转化/说清概念… |
| **S** Style | 呈现风格 | 散文/教程/口播… |
| **T** Tone | 语气 | 温暖/专业/犀利… |
| **A** Audience | 受众 | 谁、在哪读 |
| **R** Requirements | 约束与必含 | 字数、结构、关键词、禁词 |

## Fill template

```text
【CO-STAR】
C（背景）：…
O（目标）：…
S（风格）：…
T（语气）：…
A（受众）：…
R（要求）：…
```

## Draft procedure

1. Emit filled CO-STAR block.
2. Draft copy that hits O for A, in S+T, obeying R.
3. Footer: `framework: CO-STAR`.

## Mini example

```text
C：精品咖啡「山间豆」；云南保山海拔1800m+ 阿拉比卡
O：吸引25–35岁城市女性，引导点评论区购体验装
S：治愈系散文，像朋友分享
T：温暖、真诚、略带诗意
A：小红书生活方式向女性用户
R：~300字；标题+正文+3标签+封面建议；必含「手工采摘」「高山种植」
```
