# Method: STAR

**id:** `star` · **load this file before drafting when STAR is selected.**

## When

新手、快速结构化一稿、「先给个结构」、短请求。

## Slots (fill all)

| Slot | Meaning | Fill rule |
|------|---------|-----------|
| **S** Situation | 背景/项目处境 | 谁、在什么渠道、什么产品/主题 |
| **T** Task | 具体任务 | 体裁 + 主题 + 字数 |
| **A** Action | 方法与规范 | 风格、必含点、禁词 |
| **R** Result | 输出格式 | 标题/正文/标签/分段等 |

一句话：**背景 + 任务 + 约束 + 格式**。

## Fill template (show before draft unless user forbids)

```text
【STAR】
S（背景）：…
T（任务）：…
A（约束）：…
R（格式）：…
```

## Draft procedure

1. Emit filled STAR block.
2. Write the deliverable that satisfies T+A+R.
3. Footer: `framework: STAR`.

## Mini example

```text
S：新品牌「山间豆」小红书推广
T：约300字产地故事
A：温暖治愈；必含「手工采摘」「高山种植」；禁用「顶级」「最好」
R：标题 + 正文 + 3个话题标签
```
