# 提示词设计七大核心原则

设计任何写作提示词前先落实这七条。

| 原则 | 核心含义 | 错误 ❌ | 正确 ✅ |
|------|----------|---------|---------|
| 明确需求和目标 | 说清用途与要求 | 「帮我写一个柿饼制作过程的短视频脚本」 | 「…短视频脚本，背景为乡村，突出中国传统美食与乡土风情」 |
| 将复杂任务拆解 | 大任务拆成小步骤 | 一次生成完整小说 | 确认创意 → 大纲 → 逐章 |
| 使用关键词与结构化语言 | 「总结 / 分析 / 对比 / 不超过500字」 | 「写得生动一点」 | 「用视觉化语言描写雨天校园：人物、声音、气味」 |
| 避免歧义与模糊 | 不用无标准表达 | 「尽量详细」 | 同上，给可检查细节 |
| 补充上下文 | 给足背景 | 「写一段校园生活开场白」 | 「面向一年级新生，抖音推广，目标涨粉与互动」 |
| 设定明确边界 | 长度、风格、禁词 | 无限制 | 「轻松幽默约300字，适合直播开场」 |
| 测试与迭代 | 提示词需多轮打磨 | 写完不再改 | 按输出持续收紧约束 |

**核心公式：** 优质输出 =（精准描述 + 风格约束）× 参数调控

框架的本质是降低沟通成本：把隐性知识显性化，减少模型猜测，让「带约束、给示例、明确格式」可重复执行。
